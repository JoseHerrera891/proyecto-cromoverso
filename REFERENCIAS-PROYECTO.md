# Referencias del proyecto Cromoverso

Este archivo reúne las fuentes oficiales compartidas para implementar y verificar el proyecto. Consultarlas antes de cambiar pantallas, navegación o integración con la API.

## API y contrato

- [Documentación interactiva de la API](https://yanethm-cromoverso-api.fly.dev/docs)
- [Contrato por vista](https://yanethm-cromoverso-api.fly.dev/docs/contrato)
- [Contrato en Markdown](https://yanethm-cromoverso-api.fly.dev/docs/contrato.md)
- [Base de la API v1](https://yanethm-cromoverso-api.fly.dev/api/v1)

La respuesta de la base de la API identifica el servicio como `cromoverso-api`, versión `1.0.0`, y enlaza su documentación y contrato. El contrato indica que describe las vistas, sus endpoints, datos enviados y respuestas.

## Diseño

- [Recursos de diseño](https://yanethm-cromoverso-api.fly.dev/docs/diseno/)

La página publica colores, tipografía, espaciados, radios, sombras, iconos y logo. Usar sus valores como referencia de diseño vigente.

## Capturas compartidas

Las imágenes compartidas en la conversación muestran referencias de escritorio y móvil para:

- Inicio público y catálogo de un mundo.
- Aviso inicial de cookies.
- Selector de idioma español/inglés.
- Menú móvil.
- Panel de accesibilidad.

Otra captura muestra una lista de 16 archivos adjuntos de componentes React y CSS: `BannerCookies`, `Footer`, `GestorCookies`, `LayoutPublico`, `MenuMovil`, `SelectorIdioma`, `PreferenciasCookies` y `HeroCromoverso`. Algunos nombres aparecen truncados en la captura. La imagen no incluye el contenido de esos archivos; solicitar los archivos reales antes de integrarlos.

Las capturas permanecen como adjuntos de la conversación; este documento guarda su descripción y las fuentes oficiales, no copia las imágenes al repositorio.
